# 功能范围台账

`ledger.json`沿用100分功能规划权重，定义见[唯一交付计划](../delivery-plan.md)。这是范围管理，不是官方评分或已测得的完成百分比。

大项只有整体契约闭环才可标记“验收通过”。有限样例通过不意味着字面量工具、反向NFA或有界回溯整个公共模块已经完成；这些项目前标记“有差异”。这里没有发布完成率，也不能把保守的未闭环计分解释成项目没有完成任何工作。

`scripts/check_coverage.py`检查编号、权重和证据路径。测试文件存在只是引用完整，不是已执行通过的证据；实际运行状态见`docs/validation/latest.json`。下一阶段要拆出可逐条验收的行为项，再进行可信的加权汇总。不能把“解释了不兼容”算作“已经等价实现”。

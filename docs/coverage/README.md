在继续实现之前已经锁定的可选分数：

- A5 的 1 分：公开的大小限制和嵌套限制错误。`dfaSizeLimit` 仍是字符串步进缓存的预算。`Send`、`Sync` 和 Rust 内存布局不在这 1 分里。
- C4 的 2 分：捕获元信息，以及 `SetMatches` 的双向迭代。C1/C3 已经列出的输入和 PikeVM 捕获不在这里再计一次。
- E 的 1 分：上游 `regex-cli find match` 的 NFA/PikeVM 命令，比较跨度输出和退出码。本仓库的演示 CLI 不能抵扣。生成和序列化命令不在这 1 分里。
